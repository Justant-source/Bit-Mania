Bit-Mania · Phase 5

깔끔하고 조용한, 운영 가능한 트레이딩 대시보드

이 문서는 Bit-Mania 대시보드의 단일 진실 공급원입니다. 모든 색, 타입, 컴포넌트는 아래 :root 토큰에서 파생됩니다. 새로운 화면을 추가할 때는 토큰과 컴포넌트만 조합하세요 — 절대 임의 색상이나 인라인 스타일을 넣지 않습니다.

원칙 1 · 조용함

포지션을 가진 시스템은 시끄러우면 안 됩니다. 그라데이션·드롭쉐도우·이모지를 최소화하고, 숫자와 추세에 시선이 가도록 회색–흰색 베이스에 한 가지 블루 액센트만 씁니다.

원칙 2 · 신호 우선

색은 의미를 가질 때만 씁니다. 초록=이익/정상, 빨강=손실/경보, 노랑=주의, 파랑=정보. 중립 텍스트에 컬러를 쓰지 않습니다.

원칙 3 · 한 시스템, 두 테마

라이트는 낮 운영 화면, 다크는 새벽 모니터링용입니다. 토큰 한 셋이 두 테마를 모두 만들어내므로, 컴포넌트는 테마를 알 필요가 없습니다.

04 · How to use

새 화면을 만들 때

새 페이지가 필요해질 때 따라야 할 5가지 체크리스트.

DO
  • 모든 색은 토큰 변수에서 가져온다 (var(--text-muted) 등).
  • 레이아웃은 app-shell + sidebar + topbar + page 구조.
  • 숫자는 .mono + font-variant-numeric: tabular-nums.
  • 상태 색은 .pos / .neg / .warn 또는 badge 컴포넌트로만.
  • 새 컴포넌트가 필요하면 먼저 이 페이지에 추가한다 (단일 진실 공급원).
DON'T
  • 인라인 style="color:#xxx" 으로 하드코딩하지 않는다.
  • 이모지를 정보 표현에 쓰지 않는다 (배지·아이콘으로 대체).
  • 그라데이션은 로고 외에 쓰지 않는다.
  • 그림자를 두 단계 이상 쌓지 않는다 — 시각적 노이즈.
  • 같은 정보를 두 가지 색/스타일로 동시에 표현하지 않는다.
파일 구조 제안
dashboard/
├── design/
│   ├── index.html              # 이 문서 — 디자인 시스템 단일 진실 공급원
│   └── README.md               # 토큰 사용 가이드 + 기여 방법
└── src/public/
    └── css/
        ├── tokens.css          # :root + [data-theme="dark"] 변수만
        ├── components.css      # .btn .badge .kpi .tbl .card 등
        └── dashboard.css       # 페이지-특수 레이아웃 (얇게)

이 index.html의 <style> 블록 첫 두 부분 (TOKENS, COMPONENTS)을 그대로 tokens.css + components.css로 분리하면 됩니다. 새 화면은 이 두 파일만 import 하고 페이지별 클래스만 추가하세요.
