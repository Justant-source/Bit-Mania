# 1. 이 세션에서 한 작업 — 독립 재검증

v12 리포트를 그대로 믿지 않고, `grid_scores_full.parquet`(1,536×37 컬럼)을 직접 로드해 계산을
재현했고, VERDICT.md가 다루지 않은 각도 3가지를 추가로 측정했다. 사용한 스크래치 스크립트는
세션 종료 시 정리되므로(스크래치패드), 재현 가능하도록 아래에 로직을 기록한다.

## 1.1 NO_PLATEAU 재확인 (완전 일치)

`replay_lib.py`를 import해 hard_pass/plateau 로직을 독립 재구현 → 56/1,536 hard_pass, plateau 0개,
최대 이웃비율 0.625로 **완전 일치**. v12 리포트에 오류 없음.

## 1.2 C1 임계값 민감도 (VERDICT.md에 없던 측정)

MDD 임계값을 바꿔가며 hard_pass/plateau 개수가 어떻게 변하는지 스캔:

```
MDD>= -60.000: hard_pass=    0  plateau=   0
MDD>= -64.000: hard_pass=   17  plateau=   0
MDD>= -66.697: hard_pass=   56  plateau=   0   ← #7908 기준선 (실제 사용된 값)
MDD>= -68.000: hard_pass=   73  plateau=   1
MDD>= -70.000: hard_pass=  159  plateau=  21
MDD>= -72.000: hard_pass=  283  plateau=  75
MDD>= -74.000: hard_pass=  391  plateau= 178
```

`#7908`의 설계구간 MDD(−66.697%)는 격자 1,536개 중 **94.8 백분위**(상위 5.2%) — 즉 통과 기준으로
쓰기엔 이미 격자의 극단값에 가깝다. NO_PLATEAU는 "탐색이 실패했다"는 신호라기보다, **`#7908` 자체가
이 파라미터군에서 이미 MDD 우수 극단에 있어서 그 위로 넘는 조합이 조밀한 이웃을 이루기 어렵다는
기하학적 결과**에 더 가깝다.

## 1.3 MDD 판별력의 단일 사건 집중 (N=1 문제)

15개 블록 각각과 전체 MDD의 상관계수를 격자 전체(1,536)에서 계산:

```
block    corr_with_mdd
2022-04       0.855   ← 압도적 1위
2022-10       0.766   ← 2위
2019-10      -0.388
2021-10       0.541
(나머지 블록 |corr| < 0.3)
```

C1(MDD 하드 제약)이 사실상 고르는 것은 "2022년 하락장에서 덜 잃은 조합"에 가깝다. 15블록 중
1~2개 사건이 통과/탈락을 지배한다.

## 1.4 `#7908`의 실제 이웃 — 격자가 측정하지 않은 지점

격자는 `#7908`의 정확한 좌표(st_period=9, slow_ema=29, dir_ema=240)를 **의도적으로 피해** 설계됐다
(사전등록 §5, "현행값이 유리해지지 않게"). 그 결과 `#7908`의 실제 ±1-스텝 이웃은 v12 격자 안에
한 번도 없다. `replay_lib.run()`으로 `#7908` 기준 실제 스텝(st_factor±0.1/0.2, st_period±1/2,
fast_ema±1/2, slow_ema±1/2, dir_ema±10/20) 20개를 직접 실행:

```
fast_ema  7→6 (나머지 #7908 동일): MDD -66.70→-64.45 (+2.25)  CAGR 266.25→267.81 (+1.55)  s_raw 0.324→0.412 (+0.088)
   → 세 지표 모두에서 #7908을 지배
slow_ema 29→27: MDD -66.70→-59.55 (+7.15)   dir_ema 240→260: MDD -66.70→-76.31 (-9.61)
st_factor 2.6→2.4: MDD -66.70→-65.09 (+1.61) CAGR 266.25→275.59 (+9.34)
```

이웃 20개 중 MDD가 `#7908`보다 나은 것이 다수 존재한다 — 그런데 v12 격자(dir_ema step 40,
slow_ema step 3)는 이 스케일(dir_ema 10 → MDD 6%p 변화, slow_ema 1 → 4~7%p 변화)보다 3~4배
거칠어서, 어떤 점도 "이웃과 동떨어진 고립점"으로 보이게 만드는 해상도 문제가 있다.

**결론**: v12의 NO_PLATEAU는 옳지만, 정밀 격자를 썼다면 plateau가 나왔을 수도 있다는 의심이 남는다
— 그래서 §2로 넘어가 실측했다.

# 2. 결정적 검정 — "더 촘촘히 파면 나아지는가?"를 실측

VERDICT.md는 "`dir_ema≈200-220 & fast_ema≤6` 방향이 세 번 독립 재현됐으니 v13 미세격자로 검정할
가치가 있다"고 남겼다. 이 세션에서는 **그 방향을 별도 사전등록 없이 파는 대신, 이미 있는 홀드아웃
(2025-01-01~2026-08-28, 20개월, v12 Phase 4가 손대지 않은 구간)에 그대로 옮겨 전이 여부를 쟀다.**

## 2.1 fast_ema 축 — 설계구간 vs 홀드아웃 (다른 축은 전부 `#7908` 고정)

```
fast_ema:        4      5      6      7      8      9     10
설계구간 MDD:  -62.5  -62.9  -64.4  -66.7  -72.4  -74.8  -77.4   ← 완벽한 단조 개선(작을수록 좋음)
홀드아웃 MDD:  -50.7  -48.0  -49.7  -52.1  -53.0  -48.1  -48.0   ← 패턴 없음

순위상관(Spearman) = -0.07
```

프로그램 전체에서 세 번(v11a Jesse, phaseA 603-표본 replay, v12 1,536격자) 독립 재현됐던 "fast_ema
낮을수록 유리" 효과가, 실제 미래 구간(홀드아웃)에서는 **완전히 사라진다.** 설계구간 최악(fe=10,
−77.4%)이 홀드아웃에서는 최선급(−48.0%)이다.

## 2.2 결정적 검정 — 1,536개 전체를 홀드아웃에 재실행 (병렬 8코어, 54초)

"선별 절차 자체가 정보를 갖는가"를 직접 측정. 각 combo를 설계구간과 별개로 홀드아웃 구간
(2025-01-01~2026-08-29, $10,000 독립 시작)에서 재실행하고, 설계구간 순위와의 Spearman 상관을 계산.

```
설계구간 지표    →  홀드아웃 지표         rho        p-value
design s_raw     →  holdout net_pct     -0.508    p≈1e-101   ← v12의 채점함수. 강한 음의 상관!
design s_raw     →  holdout Sharpe      -0.502
design s_raw     →  holdout net@15bps   -0.483
design CAGR      →  holdout net_pct     +0.030    p=0.25     ← 사실상 무상관
design MDD       →  holdout MDD         +0.148    p=5.7e-9   ← 통계적으로 유의하나 효과 미미
```

| 선별 방식 | 홀드아웃 net 중앙값 | 15bps 슬리피지 적용 시 |
|---|---:|---:|
| **무작위 (격자 1,536 전체 중앙값)** | **+27.8%** | **−10.8%** |
| v12 hard_pass 56개 (C1∩C2∩C3) | +4.4% | −30.6% |
| 설계구간 MDD 상위 50 | +9.2% | −27.2% |
| 설계구간 s_raw 상위 50 | +4.6% | −27.3% |
| 설계구간 CAGR 상위 50 | +43.3% | +1.9% |

**v12의 선별 기준(C1–C3 하드제약, s_raw 채점함수)은 무작위 추출보다 홀드아웃 성과가 나쁘다.**
홀드아웃 최상위 8개 조합을 역추적하면 전부 설계구간 **하위 10~20 백분위**(CAGR pct 0.2~22,
MDD pct 8~19)에 있다 — 순위가 사실상 반전돼 있다.

> **중요한 재해석**: v12가 NO_PLATEAU로 멈춘 것은 결과적으로 옳았지만, 그 이유는 VERDICT.md가
> 적은 "plateau가 없어서 후보가 없었다"보다 더 근본적이다 — **애초에 이 선별 기준으로 후보를
> 찾았어도 그게 미래에 도움이 안 됐을 것**이다. 사전등록 규칙(§9 "그 외 → `#7908` 유지")을
> 지킨 것 자체가, 몰랐던 채로 올바른 선택이었다.

## 2.3 다른 축은? (dir_ema, slow_ema, st_factor 개별 확인)

```
dir_ema축:   design→holdout MDD 순위상관 = +0.714  (유일하게 방향이 살아있는 축)
slow_ema축:  design→holdout MDD 순위상관 =  0.000
```

# 4. 결론 — 파라미터 탐색은 여기서 종료 권고

**이유는 "안 찾아져서"가 아니라, "찾는 행위 자체가 측정상 작동하지 않음을 확인했기 때문"이다.**

1. **오라클 상한이 무의미**: 격자 전체 최고 MDD는 −60.88%로 `#7908` 대비 5.82%p 개선인데
   대가가 CAGR −69.2%p. 1,536개 중 CAGR·MDD **동시** 우위 조합 = 0개. 프론티어는 순수
   트레이드오프이고 `#7908`은 이미 그 위에 있다.
2. **판별 통계량이 사실상 N=1~2**: MDD 순위의 대부분이 2022년 한 사건(§1.3)으로 결정된다.
3. **전이가 0 또는 음수(§2.2)**: 설계구간에서의 우위가 홀드아웃에서 사라지거나 역전된다.
   이건 "격자를 더 넓히거나 촘촘히 하면 나아질" 문제가 아니다 — 선별 기준 자체가 홀드아웃과
   반상관이므로, 더 정밀하게 파도 같은 방향(무작위보다 나쁜 선택)으로 수렴할 뿐이다.
4. **독립 2회 재현**: v11(Jesse 2,493×8 격자 → 채택후보 5개 전원 홀드아웃 탈락)과 v12(전이
   ρ≈0/음수)가 서로 다른 엔진·다른 선별지표로 같은 결론에 도달.
5. **개선폭이 결과를 바꾸지 못함**: 3x 레버리지에서는 MDD −67%든 −63%든 실질적으로 같은
   재앙 수준.

VERDICT.md가 "v13 후보"로 남겨둔 `dir_ema≈200-220 & fast_ema≤6` 방향은 **이 세션에서 홀드아웃에
투영해 반증됐다** — 별도 사전등록으로 v13을 도는 것은 권장하지 않는다.

# 6. 고지 — 홀드아웃 오염

§2.2의 전이검정을 위해 격자 1,536개 전체를 홀드아웃 구간(2025-01-01~2026-08-28)에 실행했다.
**이로써 이 구간은 더 이상 v12 프로토콜상 "깨끗한" 홀드아웃이 아니다.** 결론이 "탐색 종료"이므로
이번 세션에서는 비용 대비 가치가 있다고 판단했으나, 향후 다시 파라미터 연구를 재개한다면 새
홀드아웃은 **2026-08-28 이후 라이브에 새로 쌓이는 데이터**여야 한다.

라이브 yaml · Kill Switch · 레버리지 · `BYBIT_TESTNET`는 이 세션에서 **전혀 변경하지 않았다.**
