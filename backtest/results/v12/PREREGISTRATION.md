# 5. Phase 2 격자 (1,536 combo, 이후 변경 금지)

```json
{ "st_factor": [2.0, 2.2, 2.4, 2.6, 2.8, 3.0],
  "st_period": [6, 8, 10, 12],
  "fast_ema":  [4, 6, 8, 10],

  "dir_ema":   [180, 220, 260, 300],
  "atr_mult":  [3.3] }
```
= 6×4×4×4×4 = **1,536**. `atr_mult` 고정(v10에서 무의미 검증됨). `#7908`(2.6/9/7/29/240)은 격자 꼭짓점이 아님 — 의도적으로 현행값이 유리해지지 않게 함.

2차 세밀화(§5.2, half-step): 1차 결과에서 최상위 plateau가 특정되면 그 주변만. **"더 좋은 점 찾기"에 쓰지 않는다** — 오직 매끄러움(진짜 plateau vs 톱니) 확인용. 최종 파라미터는 세밀화 결과의 최고점이 아니라 **plateau 기하학적 중심**.

# 6. 점수 함수 (단 하나, 사전등록)

```
lg_b   = 블록 b의 로그성장 (하나의 연속 equity curve를 블록으로 절단 — Jesse의 "윈도우 독립+평균" 아님)
S_raw  = median_b(lg_b)                                    ← 이상치(2020-21형) 지배 방지
S      = mean( S_raw(self), S_raw(모든 grid 이웃) )         ← plateau 평활, ±1 step, 5축, atr 제외
```
