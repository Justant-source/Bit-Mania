# 004 — 추세추종 (Trend Following)

## 전략 개요

추세추종 전략은 가격 추세의 방향을 감지하여 이를 추종하는 전략입니다. 기술적 지표(EMA, Donchian, ADX, MACD, Bollinger Bands)를 사용하여 상승/하강 추세를 판별하고 롱/숏 포지션을 진입/청산합니다. 특히 대주기 추세장에서 큰 움직임을 포착하는 것을 목표로 합니다.

**핵심 지표**:
- EMA Cross (20/50/200), Triple EMA
- Donchian Breakout (채널 돌파)
- ADX Momentum (방향성 지표)
- MACD + Bollinger Bands

## 폐기 이유

### 1. 수수료 초과 (Fee Killing)

**수수료 구조**:
- Bybit 선물 taker: 0.055% (편도)
- 현물 거래: 0.01% (편도)
- 왕복 수수료: 약 0.27% (1회 진입~청산)
- 슬리피지: 0.06% (entry 0.03% + exit 0.03%)
- **총 비용: 0.33%/거래**

**거래 빈도**:
- Donchian: 558회 (6년) = 약 93회/년 = 거의 2회/주
- EMA Cross: 1,553회 = 약 259회/년 = 3회/주 (수수료 악화)

**수익 vs 수수료**:
- 6년 연수익: -1.84% (Donchian 기준)
- 거래당 평균 손실: -1.84% / 558회 = -0.0033% (음수)
- 추정 gross alpha: 수수료 0.27%를 초과하지 못함 → **수수료가 수익을 먹어치움**

### 2. 추세 포착 실패

**이론적 기대**:
- 추세추종은 큰 추세(2022년 -70%, 2021년 +500%)를 포착하여 큰 수익을 거둬야 함

**실제 결과**:
- 2022년 폭락 (-70%): **숏 수익 없음**, Donchian -1.99%
- 2023-24 불장 (+120%): Donchian +7.46% (기대값 훨씬 낮음)

**원인**:
- BTC 추세 중에도 단기 반등이 빈번 → 손절 발생
- 수수료 + 슬리피지가 작은 손절을 반복 → 누적 손실 초과

### 3. 높은 거래 빈도의 함정

- 거래 횟수 증가 (500~2000회) = 수수료 누적
- 슬리피지 노출 증가 (각 거래마다 0.03%)
- API 호출 및 시스템 부하 증가
- FA와 비교하면 거래수 3~10배 많으면서 수익은 낮음

### 4. Walk-Forward 불합격

- FA+TF(donchian) Walk-Forward Sharpe: 0.777 (기준 ≥ 1.0 미달)
- 일관성: 54.5% (기준 ≥ 70% 미달)
- **연수익**: 1.27% (단순 현금 이자 수준)

### 5. FA가 압도

| 메트릭 | FA 단독 | FA+TF 최적 | 차이 |
|------|--------|-----------|------|
| Sharpe | 7.295 | 0.484 | **FA가 15배 우수** |
| MDD | 0.25% | 3.42% | FA가 14배 안전 |
| 연수익 | 2.04% | 1.22% | FA가 1.7배 높음 |
| 거래수 | 198 | 742 | TF 추가로 3.7배 증가 |

**결론**: TF 추가의 모든 지표가 악화

## 교훈

1. **선물 시장의 높은 거래 비용**
   - 현물은 수수료 0.01%, 선물은 0.055% (5배)
   - 추세추종은 높은 거래 빈도 필수 → 선물 환경에 부적합
   - 수수료 < alpha 조건을 만족하기 어려움

2. **기술적 지표의 한계**
   - EMA, Donchian 모두 후행 지표
   - 급격한 폭락(하루 -20%)에는 반응 지연
   - 단기 노이즈(반등)에 의한 손절 반복 (수수료 증가)

3. **BTC 선물 시장의 특성**
   - 거래소 매매 차이(bid/ask spread) 큼
   - 유동성 부족 구간에서 슬리피지 심함
   - 펀딩비 급변 → 추세와 무관한 청산 위험

4. **추세 포착의 역설**
   - 이론: "큰 추세를 포착하면 큰 수익"
   - 현실: 추세 확인 후 진입하면 이미 수익의 상당 부분 소진
   - 추세 초입 진입은 노이즈와 구분 어려움

5. **포트폴리오 관점**
   - FA (Sharpe 7.3) + TF (Sharpe -0.2) 결합은 평균 0.5 수준으로 악화
   - 단순 가중평균 계산 (50:50) = Sharpe 3.5인데 실제는 0.5
   - → TF의 높은 변동성/손실이 FA 포트폴리오 전체를 드래그

6. **대안 경로**
   - 추세추종 → **현물 매수 재투자로 대체** (수수료 낮음, 장기 추세 수익 가능)
   - FA + 현물 재투자 30% = 포트폴리오 수익 +78.63% (6년)
   - 이는 FA+TF 결합(+1.22%)보다 64배 우수
