# 006 — 변동성 스퀴즈 + HMM 레짐 필터

## 전략 개요

**가설**: 볼린저 밴드(20,2)가 켈트너 채널(20, 1.5×ATR) 안으로 수축한 "스퀴즈" 상태 후 가격이 BB 외부로 종가 돌파할 때 진입. Hidden Markov Model (GaussianHMM) 3-state 레짐 모델로 고변동 상태에서만 거래하여 가짜 돌파를 필터링. BTC의 "저변동성 → 변동성 폭발" 패턴은 모든 사이클에서 반복된다는 가설.

**수익 원천**: 변동성 압축 후 팽창 구간의 10~25% 대형 추세  
**거래 빈도**: 연 12~20회 (월 1~2회, 이상적)  
**기대 수익**: 거래당 10~25% 목표 vs 왕복 0.04%(메이커) → 수익 대비 수수료 0.16~0.4%

**영향**:

- Sharpe 수치 신뢰불가 (표본이 너무 작음)

### 3. 신호 설계의 구조적 결함 (치명)

```

  All Days: 1,101일 (100%)

    ↓ (BB/KC 동시 기준, 거래량, RSI, HMM)
  Valid Entry: ~7일 (0.6%) ← 극단적 희소화

```

**해결책**:
1. HMM을 필터 대신 **사이징**으로 사용
2. 또는 **지표 재설계** (스퀴즈 + MACD, 스퀴즈 + 펀딩비 등)

v3에서 1번 시도했으나 거래 8회로 미흡 → 2번 필요 (작업량 2~3주)

### 4. 오버피팅된 Sharpe 수치

**문제**: Stage 1 Sharpe 12.896은 신뢰불가

원인들:
1. **표본 부족**: N=7로 Sharpe 수치가 극도로 높음 (N↓ → Sharpe↑)
2. **기준값 오류**: `periods_per_year=365` 오류 → 20% 과대 계산
3. **100% 승률**: 손실 거래 0건 → 분모(변동성) 극소화

**증거**: v3에서 완화된 파라미터로 8거래 → Sharpe 0.228 (극락)
= v2 Sharpe 12.896은 **참 수치가 0.2~0.5 범위**일 가능성

## 교훈

### 1. "저빈도 전략"의 함정

```
이상적 가정:
  "월 1~2회 거래 = 저빈도 = 수수료 무력화"

현실:
  거래 빈도가 너무 낮으면 파라미터 검증 불가능
  N=7에서 최적화는 통계적으로 무의미
  
교훈: 저빈도 전략도 최소 연 50회 이상 필요
```

### 2. 다중 필터의 위험성

```
필터 1: squeeze_off == True           (통과율 ~2.7%)
필터 2: BB 기준 동시 만족             (통과율 ~50%)
필터 3: 거래량 > SMA × 1.5            (통과율 ~60%)
필터 4: RSI 범위 50±                  (통과율 ~60%)
필터 5: HMM state ≥ 1                 (통과율 ~80%)

최종 통과율: 2.7% × 50% × 60% × 60% × 80% = 0.39%
→ 연 1,101일 × 0.39% = 4일 = 극단적 희소

올바른 설계:
  필터 1 또는 필터 2 (선택적 AND)
  → 통과율 2.7% + (1-2.7%) × 50% = ~25%
  → 연 275일 가량 신호 발생
```

### 3. HMM "필터" vs "사이징"

```
v2 설계 (HMM을 필터로):
  "고변동 상태(State 2)에서만 거래"
  → 23.3% 확률로만 거래 가능
  → 신호 80% 손실

개선된 설계 (HMM을 사이징으로):
  "모든 돌파에서 거래, 다만 State 2면 위치 2배"
  → 거래 빈도 보존
  → 위험관리 강화
```

v3에서 시도했으나 아직 부족 (Config C 검증 필요)

### 4. 표본 크기의 중요성

| 거래 수 | Sharpe 신뢰도 | 평가 |
|--------|------------|------|
| < 10 | 극히 낮음 | **논문 불가** |
| 10~30 | 낮음 | **조건부 검증** |
| 30~100 | 중간 | 신뢰 가능 |
| > 100 | 높음 | **충분** |

**이 전략**: N=7 → Sharpe 신뢰도 불가능
(거래당 이득 극소 + 변동성 극소 → 수치 극과장)
