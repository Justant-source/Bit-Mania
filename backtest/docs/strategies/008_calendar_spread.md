# 008 — 캘린더 스프레드 (Calendar Spread Arbitrage)

## 전략 개요

분기물(Quarterly Futures) 무기한(Perpetual) 간 스프레드를 매매하여 베이시스 수렴 + 펀딩비 이중 수익을 목표로 하는 차익거래 전략.

**수익 원천**: 
- 베이시스 결정론적 수렴 (분기물은 만기에 현물가로 수렴)
- 펀딩비 캐리 (펀딩비 수취)

**거래 빈도**: 분기당 4~8회 (연 16~32회)  
**포지션**: 롱 무기한 + 숏 분기물 (델타 뉴트럴)  
**이론적 근거**: BIS Working Paper 1087 — 분기 베이시스는 구조적으로 평균회귀적

#### 합성 데이터 특성

**고정 베이시스 2.5% 문제**:
```
합성 공식: quarterly_price = perpetual_price × 1.025

실제 베이시스: 1.0% ~ 4.0% (동적, 시장 환경 반영)
합성 베이시스: 2.5% (정적, 시간 불변)
```

- 베이시스 변동 0 → 신호 거의 발동 안 함
- 9거래 모두 음수 결과
- 전략 유효성 검증 불가능

### Round 2 — v3 재검증 (2026-04-11)

**개선사항**: 이자율 기반 동적 베이시스 모델

```python
# v3: 개선된 합성 데이터
risk_free_rate = 5.0%  # 연이율
funding_annualized = avg(funding_rate) × 365 × 8
dte_days = 90

basis_pct = (rfr × DTE/365) + (funding_annualized × DTE/365 × 0.3)
quarterly_price = perp_price × (1.0 + basis_pct/100) + noise(±0.3%)
```

**현실성 평가**:
- v2 (고정 2.5%): 현실과 거리 먼 평탄한 콘탱고
- v3 (이자율 기반): 시장 기초 이론 기반, 실데이터 없을 시 차선책

**v3 결과**: 데이터 부재로 재실행 미완

## 폐기 이유

### 1차 원인: 실제 분기물 데이터 부재 (확정)

**데이터 조사 결과**:
- `quarterly_futures_history` 테이블: 존재하나 **0 rows**
- Bybit API: 실시간 데이터만 제공, 히스토리 미제공
- Binance Vision: COIN-M 분기물 아카이브 없음 (USDⓂ-M 선물만)
- CoinMetrics: 유료 API 필요

**영향**:
- 3년 데이터 불확보로 백테스트 신뢰성 0
- 합성 데이터 기반 성과는 실전 배포 시 재현 불가능

### 2차 원인: 베이시스 구조의 불확실성

실제 분기물 베이시스는 여러 요인에 따라 동적으로 변함:
```
강세장 (콘탱고): 5~8%
정상 환경: 1~3%
역베이시스 (약세장): -1% ~ -3%
만기 1주일 전: 0%에 수렴
```

고정된 합성 모델로는 이러한 변동성을 재현할 수 없음.

### 3차 원인: 거래 신량 극소

- 합성 데이터 기반: 9거래/3년 (월 0.25회)
- 기대: 분기당 4~8회
- **신호 신뢰성 검증 불가능** (표본 크기 부족)

## 교훈

1. **데이터 가용성의 절대적 중요성**: 차익거래 전략은 정확한 가격 데이터가 생명. 합성 데이터는 평가 도구가 아님.

2. **시계열 데이터의 오염 위험**: 고정 기저(2.5%)로 동적 현상(베이시스)을 재현하려 하면 과적합과 낙관편향 위험.

3. **거래소 API 한계**: 코인 거래소들은 현물 데이터에 비해 파생상품 히스토리 제공에 인색함.
