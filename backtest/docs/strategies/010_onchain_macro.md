# 010 — 온체인 매크로 복합 신호 (On-chain Macro Composite)

## 전략 개요

7개 온체인/매크로 지표를 결합하여 비트코인 사이클의 극단 신호만 포착하는 저빈도 고정확도 전략.

**측정 지표**:
1. MVRV Z-Score (시장 주기)
2. aSOPR (매도 압력)
3. 거래소순유출 (상승장 신호)
4. Fear & Greed Index (심리)
5. DXY 역상관 (매크로)
6. ETF 플로우 (기관 자본)
7. 펀딩비 과열도 (레버리지 정도)

**거래 빈도**: 예상 6~10회/년 (극단 신호 희소성)  
**진입 기준**: 복합점수 ≥5/7  
**포지션**: 롱, 레버리지 1~3x

## 폐기 이유

### 1차 원인: 신호 구조 설계 결함 (확정)

**근본 문제**: 7개 지표 동시 확인은 **통계적으로 불가능**

```
각 지표의 극단 신호 빈도:
  MVRV Z < -1.5: ~10~15% (월 3~4일)
  aSOPR < 0.1: 극히 드묾
  거래소순유출 > 2σ: ~5~10%
  Fear & Greed < 25: ~5%
  DXY > 1.5σ: ~10%
  ETF 대량유입: ~5%
  펀딩 > 0.015%/8h: ~15%

동시 만족 확률: 0.1 × 0.05 × 0.1 × 0.05 × 0.1 × 0.05 × 0.15
           = 0.000000375 (3년간 0회)
```

### 2차 원인: 데이터 오염 (90% 합성)

**CoinMetrics Pro API 403 에러**:
- MVRV Z-Score, aSOPR, NVT 지표 Pro 전용
- Community API로 대체 불가능
- 무음 폴백으로 합성 데이터 사용

**합성 데이터의 문제**:
```
Pro MVRV 범위: -0.5 ~ 9.0 (실제 사이클)
합성 MVRV: 0.5 ~ 3.2 (극단값 평활화)
→ 극단 신호 감지 불가능
```

### 3차 원인: MVRV 단독의 제한성

**MVRV 단독 결과**:
- 거래 17회 (3년간, 월 0.5회)
- CAGR +8.24% (제한적 성과)
- **표본 크기 < 20** → 통계적 유의성 부족

**평가**:
- 신호는 작동하지만 빈도 극소
- 전략으로 운영하기에는 신뢰도 부족

## 교훈

1. **복합 신호의 딜레마**: 여러 필터를 AND 결합하면 신호 신뢰도는 높지만 빈도가 극단으로 떨어짐. 통계적으로 평가 불가능.

2. **지표 설계의 중요성**: 각 지표의 극단성을 동시 확인하려면 수십 년의 데이터가 필요. 3년 데이터로는 부족.

3. **Pro API 의존의 위험**: 상용 데이터 서비스에 의존하면 서비스 중단/인상 시 전략이 무력화됨.

4. **온체인 지표의 한계**: 극단 신호는 이미 시장에 반영되어 있음. 선제적 거래 기회가 거의 없음.
