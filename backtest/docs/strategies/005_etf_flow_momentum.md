# 005 — ETF 플로우 모멘텀

## 전략 개요

**가설**: BTC 현물 ETF의 일별 순유입/유출 데이터의 누적 모멘텀을 방향성 신호로 사용하고, FOMC/CPI 등 매크로 이벤트 전후로 포지션을 축소하는 이벤트 드리븐 전략. 기관 자금 흐름이 가격을 선도한다는 가설에 기반.

**수익 원천**: 기관 ETF 매수/매도 압력의 방향성 모멘텀 (5~20% 스윙)  
**거래 빈도**: 월 3~6회, 평균 보유 5~15일  
**기대 수익**: 거래당 5~20% 목표 수익 vs 왕복 수수료 0.04%(메이커) → 수익 대비 수수료 0.2~0.8%

## 폐기 이유

### 1. 데이터 신뢰도 부족 (심각)

**문제**: ~80% 합성 ETF 플로우 데이터
- Farside Investors API: 403 Forbidden (스크래핑 차단)
- SoSoValue API: 도메인 확인 실패
- **폴백**: 가격 변화율 + 거래량 변화 → 프록시 생성

**영향**:
- 실제 기관 자금 흐름 vs 프록시의 일치도 미검증
- 합성 데이터가 실제 ETF 플로우의 극단값을 놓칠 가능성 높음
- 전략 재현성: 실제 ETF 데이터 사용 시 성과가 **50% 이상** 달라질 수 있음

### 2. 신호 안정성 부족 (심각)

**문제**: Walk-Forward에서 오버피팅 지표 다수

| 지표 | v2 | v3 평가 |
|------|-----|--------|
| W1~W4 OOS 성과 | IS > OOS | 행운 + 오버피팅 |
| W5 급반전 | IS 1.43 → OOS -1.29 | 신호의 지속성 미검증 |
| W6~W7 악화 | 지속적 성과 저하 | 최근 시장 적응 실패 |

**근본 원인**:
- 2024년 BTC 상승장에 과적합 (W1~W4 고성과)
- 2025년 횡보/약세 환경에서 신호 무력화 (W5~W7 악화)
- **시간대 편향**: 상승장 편향 전략 → 횡보장에서 실패

## 교훈

### 1. 외생 데이터의 투명성 필수

```
위험한 패턴:
  try:
      data = fetch_api()
  except APIError:
      data = synthetic_fallback()  # 조용히 진행 → 신뢰도 상실
      
올바른 패턴:
  data = fetch_api()  # 실패하면 RuntimeError
  # 또는 명시적: allow_synthetic=False → 사전 고지 필수
```

이 전략에서 배운 점:
- Farside/SoSoValue 같은 외생 데이터는 **미리 검증** 필수
- API 403이면 **전략 폐기** 결정을 즉시 내릴 것

### 2. 시간대 편향 감지

Walk-Forward Window별 성과의 급격한 변동은 **시간대 편향** 신호:
- W1~W4 (2024): 상승장 → 고성과
- W5~W7 (2025): 횡보/약세 → 급락

**교훈**: OOS 성과가 IS보다 높으면 **행운**, 지속 악화 추세면 **시장 변화**

### 3. 합성 데이터는 Sharpe를 거짓으로 부풀린다

- v2 Stage 1: Sharpe 1.61 (합성 신호)
- v3 재검증: Sharpe 1.26 (동일 로직)
- **폭락 -0.35 (22%)**: 합성 데이터의 노이즈 효과

합성 신호는 실제보다 **신호 대 잡음 비율이 높아 보임** → 신뢰성 낮음

### 4. 거래 빈도는 보존되어도 신호 품질은 악화된다

- 거래수: v2 70 = v3 70 (동일)
- 수익성: v2 +10.28% → v3 +9.56% (악화)
- **의미**: 거래는 동일하지만 각 거래의 품질이 하락

이는 합성 데이터의 신호 왜곡을 시사함.
