# 011 — XGBoost 멀티피처 앙상블

## 전략 개요

10개 피처(기술적 8개 + 파생 2개)를 기반으로 XGBoost 이진 분류기가 6시간 후 BTC 가격 방향을 예측하는 기계학습 전략. 워크포워드 검증으로 ~30폴드 검증.

**수익 원천**: 다중 약신호의 ML 앙상블에서 발생하는 통계적 우위  
**참고 논문**: Jaquart et al.(2021) — XGBoost가 BTC 단기 예측에서 최고 성능  
**가설**: 기술적·파생 피처 조합이 55~60% 방향 예측 정확도 달성 가능

## V5 합격 기준
- CAGR ≥ 10% (목표: 25%)
- Sharpe ≥ 1.0 (목표: 1.0+)
- MDD ≤ 15%
- WF OOS/IS ≥ 0.6
- 거래수 ≥ 30/년
- 폴드 안정성 CV < 30%

## 테스트 히스토리

### Round 1 — v2 백테스트 (2023-01 ~ 2026-03, 30폴드)

**백테스트 설정**:
- 학습 윈도우: 180일
- 검증 윈도우: 30일 (OOS)
- 롤링 간격: 30일 (겹침 없음)
- 피처: RSI(14), ATR, BB 너비, EMA 비율, 거래량 Z-점수, 수익률(1/4/28봉), 펀딩비, 펀딩비 Z-점수
- 하이퍼파라미터: max_depth=4, n_est=100, reg_alpha=1.0, reg_lambda=2.0

**결과**:
| 지표 | 값 | 목표 | 상태 |
|------|-----|------|------|
| OOS Sharpe | 0.945 | ≥1.0 | ❌ 탈락 (-5.5%) |
| OOS CAGR % | +13.59% | ≥25% | ❌ 탈락 (-45.6%) |
| OOS MDD % | -36.87% | ≤-20% | ❌ 탈락 (1.8배 악화) |
| 폴드 CV | 66.5% | <30% | ❌ 탈락 (2.2배 높음) |
| 거래수 | 362/3yr (~121/yr) | — | 충분 |

**폴드별 통계**:
- 평균 Sharpe: 0.945
- 범위: -0.338 ~ 1.684
- PASS 폴드 (Sharpe>1.0): 11/30 (37%)
- FAIL 폴드 (Sharpe<0.7): 14/30 (47%)
- CAGR 양수: 13/30 (43%)

**핵심 발견**: 
- 강한 상승 폴드(#2, #9, #24, #25, #27)는 Sharpe 1.2+
- 붕괴 폴드(#8, #29)는 Sharpe <0
- 극도의 레짐 의존성: 상승장에만 작동, 보합장에서 실패

**실패 원인**:
- **Sharpe 0.945**: 1.0 미달, 근소하지만 임계값 미달
- **CAGR 13.59%**: 필요 25% 대비 절반 이하. 수수료(0.04%) 드래그로 미소 이득 잠식
- **MDD -36.87%**: 한계 -20% 대비 1.8배 악화. 심각한 낙폭 기간 존재
- **폴드 불안정**: CV 66.5%는 2.2배 높음. 성과 예측 불가능
- **레짐 의존성**: 추세장에서만 작동, 보합장에서 붕괴

## 폐기/실패 이유

### 1. 워크포워드 성과 임계값 미달
XGBoost는 3개 기준 모두 실패:
- Sharpe 0.945 < 1.0
- CAGR 13.59% < 25%
- MDD -36.87% > -20%

5개 중 2개만 통과로 명시적 거절.

### 2. 심각한 폴드 불안정성
- Sharpe σ/μ = 66.5% (필요 <30%)
- 폴드 간 변동성이 극도로 높음
- 최고 폴드: Sharpe 1.684 (CAGR +346%)
- 최악 폴드: Sharpe -0.338 (CAGR -65.72%)
- 어떤 폴드 패턴이 반복될지 사전 예측 불가능

### 3. 구조적 레짐 의존성
- 추세장(2023 Q3-Q4, 2025 Q1): Sharpe 1.2+ (우수)
- 보합장(2023 Q1-Q2, 2025 Q3, 2026 Q1): Sharpe <0 (붕괴)
- 메커니즘: 추세 신호(EMA, 수익률)가 피처 66% 이상 차지 → 비추세 장에서 역신호

### 4. 과적합 위험 상존
- 정규화 강함 (reg_alpha=1.0, reg_lambda=2.0)에도 불구하고 불안정
- 피처 서브샘플링(0.8) + 얕은 트리(max_depth=4)도 근본 문제 해결 불가
- 25개 피처 목표 대비 10개만 사용(데이터 제약) → 예측력 낮음

## 부분 활용 가능성

**없음**. XGBoost의 극도의 레짐 의존성은 필터로도 활용 불가능. FA 전략의 진입/청산 필터로도 권고 안 함. 이유: Sharpe <1.0이므로 필터링 효과가 마진을 악화시킬 가능성 높음.

## 교훈

### ML 전략의 본질적 한계
1. **암호화폐 특수성**: 극도의 구조 변화(ETF 승인, 규제, 기관 유입)로 과거 패턴 비지속
2. **레짐 감지 필수**: ML 단독 사용 불가. 추세/보합 레짐을 사전에 감지할 메커니즘 필수
3. **수수료 드래그**: 거래당 0.04% × 362거래 = 14.5 bps 누적 → 0.945 Sharpe로는 상쇄 불가

### FA 전략이 더 견고한 이유
- 펀딩비 → 명확한 이론적 근거 (리스크 프리미엄)
- 거래 빈도 낮음 → 수수료 드래그 미소
- 레짐 독립적 → 보합장에서도 작동

### 다음 시도 방향 (비권장)
- ❌ 피처 25개로 확대: 데이터 부족 + 과적합 심화
- ❌ 하이퍼파라미터 최적화: CV 66.5% 근본 문제 해결 불가능
- ❌ 레짐 필터 추가: 추가 복잡성 대비 수익 개선 기대 낮음
- ✅ (대안) FA 거래의 보조 필터로 사용하면 거래 수 20% 감소, Sharpe 5% 개선 가능성
