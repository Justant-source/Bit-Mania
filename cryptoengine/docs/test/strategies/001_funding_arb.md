# 001 — 펀딩비 차익거래 (Funding Arbitrage, FA)

## 전략 개요

**핵심 메커니즘**: BTC 현물 Long + 선물 Short의 델타 뉴트럴 포지션을 유지하면서 정산 주기별 펀딩비 수익을 거둡니다.

- **수익 원천**: 펀딩비 (BTC 가격 변동과 무관)
- **리스크**: 거래소 수수료, 슬리피지, 헷지 미실행 위험
- **생존성**: MDD < 2%, Sharpe > 1.0 (백테스트 기준)
- **운영**: 8시간마다 진입/청산 조건 재평가

## 교훈 및 인사이트

### 1. 펀딩비 환경이 성과를 결정한다
- 2020-2021: 0.03-0.10%/8h (매우 높음) → CAGR 19-25%
- 2024: 0.01-0.02%/8h (중간) → CAGR 25.71%
- 2025+: 0.005-0.010%/8h (매우 낮음) → CAGR 1.64%
- 거래소 cap(Bybit 0.01%/8h)에 포화되면 향상 불가능

### 2. 6년 데이터가 3년보다 훨씬 엄격하다
- 3년(2023-2026) Walk-Forward: Sharpe 2.434
- 6년(2020-2026) Walk-Forward: Sharpe 0.775 (포트폴리오)
- 2022년 LUNA/3AC 폭락 + 2021 강세장 포함 여부가 결과를 크게 좌우

### 3. "short_hold" (7일)이 baseline(30일)보다 2배 성과
- 펀딩비는 7일 이상 같은 방향으로 지속되지 않는 경우 多
- 장기 보유는 역전 리스크 + 슬리피지 누적

### 4. 현물 헷지 누락이 치명적
- 실전 -24.15% 손실 원인: 부분 헷지(20%) + Kill Switch 조합 추정
- 선물 Short만 있고 현물 Long 없으면 BTC 상승 시 청산 위험

### 5. 수수료 vs 펀딩비 등식
- BEP(손익분기점) = 왕복 비용 0.19% (수수료 0.13% + 슬리피지 0.06%)
- rate=0.0001(cap) 시 19회 정산 필요 → 약 6.3일
- rate=0.00007(임계값) 시 27회 정산 필요 → 약 9.0일
- 현재 환경에서 BEP 9일 > max_hold 7일이면 항상 손실

### 6. 매크로 필터는 FA에 불필요
- FOMC/CPI ±2시간 진입 차단 = 3년간 0건 영향 (FA 정산 시각과 미겹침)
- FA는 이벤트 구동 아닌 펀딩 구동 전략
