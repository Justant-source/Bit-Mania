# 002 — 그리드 트레이딩

## 전략 개요

그리드 트레이딩은 가격 변동 범위 내에서 일정 간격의 다단 매수/매도를 반복하여 횡보장에서 수익을 목표로 하는 전략입니다. 지정된 가격대에 그리드 구간을 설정하고 각 층에서 자동으로 매/도를 반복합니다.

**핵심 파라미터**:
- Grid interval: 가격 변동폭 기준 층 나누기
- Position 크기: 각 층별 포지션 규모
- Rebalancing: 수익 실현 후 재매수

## 폐기 이유

### 1. 구조적 패배 (Structural Defeat)

추세장에서 그리드의 핵심 약점 노출:
- **상승 추세**: 가격이 그리드 상단을 돌파 → 공매도 포지션 무한 누적 → 손실 급증
- **하락 추세**: 가격이 그리드 하단을 돌파 → 매수 포지션 무한 누적 → 손실 급증
- 2025-2026 BTC 추세 시장에서 이 약점이 반복 노출됨

### 2. 수수료 부담 (Fee Killing)

- 그리드 트레이딩은 거래 횟수가 매우 높음 (3년 1,982회, 6개월 333회)
- Bybit 수수료율: 편도 0.0675%
- 왕복 수수료: 0.27% (각 거래마다 누적)
- **수익 잠재력이 수수료보다 작음**: 그리드 전략의 추정 alpha가 수수료를 상쇄하지 못함

### 3. 극단적 손실 (Catastrophic Drawdown)

- 3년 단일: MDD -86.53%
- 6년 전체: MDD -88.05%
- Walk-Forward 검증에서 일관된 손실 → 과적합이 아닌 본질적 부재

### 4. 시장 환경 변화

- 2023-2024 강세장: 상승 추세 우위
- 2025 약세장: 하락 추세 + 변동성
- 백테스트 기간(2020-2026)은 큰 추세가 여러 번 발생 → 그리드는 모든 환경에서 패배

## 교훈

1. **횡보장 특화 전략의 위험성**
   - 백테스트 기간이 상대적으로 많은 횡보를 포함하더라도, 추세장 손실이 크면 전체 성과는 음수
   - BTC 선물 시장은 본질적으로 추세 시장 → 횡보 전략은 부적합

2. **거래 횟수와 수익성의 역설**
   - 거래 횟수 증가 = 수수료 증가 → 높은 수익률이 필요
   - 그리드의 추정 alpha는 위험 조정 후 수수료를 상쇄하지 못함

3. **포트폴리오 구성 원칙**
   - 그리드 제외, FA 기반 포트폴리오 구성이 올바른 선택
   - DCA(상승장) + FA(모든 환경) + Cash(방어) 조합이 더 우수

4. **Walk-Forward의 중요성**
   - 단일 백테스트에서는 보이지 않는 약점도 22개 윈도우 Walk-Forward에서 명확히 노출
   - 모든 전략은 최소 10개 이상 윈도우 검증 필수
