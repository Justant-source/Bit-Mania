# 007 — 펀딩비 극단치 역발상 (Funding Extreme Reversal)

## 전략 개요

BTC 무기한 선물 펀딩비가 30일 이동평균 대비 ±1.5σ 이상의 극단에 도달할 때 역방향으로 진입하여 평균회귀와 펀딩비 수취를 동시에 달성하려는 전략.

**수익 원천**: 포지셔닝 과밀 평균회귀 + 펀딩비 수취  
**거래 빈도**: 월 1~2회 (저펀딩 환경에서는 연 2회)  
**핵심 가설**: 극단 고펀딩/저펀딩은 시장의 과도한 레버리지 포지셔닝을 나타내며, 이는 평균회귀하면서 역방향 수익을 가져온다.

   - CAGR: -0.43%

3. **펀딩비 역발상의 비신뢰성**
   - 극단 고펀딩 후에도 가격이 계속 상승 (추세 강화)
   - 극단 저펀딩 후에도 가격이 계속 하락 (추세 강화)
   - 펀딩비는 leading indicator가 아닌 lagging indicator

4. **Delta-Neutral 구조 부재**
   - 현재: 선물만 숏/롱 진입 (방향성 베팅)
   - 필요: 현물 롱 + 선물 숏 (진정한 펀딩 차익)
   - 펀딩비만으로는 수익이 수수료를 상쇄하지 못함

## 폐기 이유

### 1차 원인: 펀딩비 < 수수료 (치명적)

- **펀딩비 수취**: 평균 0.005%/8h × 19거래 × 3일 평균 = $12
- **수수료**: 메이커 0.02%/편도 × 2편 × 19거래 × $300 명목가 = $228
- **비율**: 0.05x (기준 2.0x 미만, 20배 차이)

연평균 펀딩비: 8시간마다 0.005% = 월 0.15% = 연 1.8%  
왕복 수수료(메이커): 0.04% ≥ 펀딩비 × 22배

### 2차 원인: 신호 부족 (저펀딩 환경 악화)

2024년 BTC 현물 ETF 승인 이후:
- 극단 펀딩비(±1.5σ) 이벤트: 월 평균 0.4건 (2019~2023: 월 3.2건)
- 거래 신호: 연 2회 (1년에 2번만 거래)
- 표본 크기 부족으로 전략 평가 불가능

### 3차 원인: 전략의 비신뢰성

펀딩비 극단치는 **후행 지표(lagging indicator)**:
- 극단 고펀딩: 이미 가격이 올랐을 때 발생 → 숏 진입 후 계속 상승
- 극단 저펀딩: 이미 가격이 내렸을 때 발생 → 롱 진입 후 계속 하락
- **평균회귀가 아니라 추세 강화 현상 발생**

### 4차 원인: 설계 결함

**Delta-Neutral 부재**:
- 현실의 펀딩 차익 = 현물 롱 + 선물 숏 (완전 헤지)
- 본 전략 = 선물 숏/롱만 (동일 방향 베팅)
- 펀딩비 수익만으로는 가격 변동 손실을 상쇄 불가능

## 교훈

1. **극단치 회귀 가설의 함정**: 거래량 스파이크, 펀딩비 극단은 시장이 이미 움직인 후의 결과. 미래 방향과 무관.

2. **수수료 구조의 중요성**: 펀딩비 연 1.8% < 수수료 연 0.04% (분기 1.6%) → 7배 차이. 초저빈도 거래는 수수료를 이길 수 없음.

3. **데이터 품질보다 전략 설계가 중요**: 데이터가 완벽해도 논리가 틀리면 실패.

4. **시장 구조 변화**: ETF 이후 기관 자본 유입 → 극단치 자동 수평화. 구조적 기회 소멸.
