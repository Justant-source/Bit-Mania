# SupertrendTrendTypeStrategy

Supertrend + TrendType 복합 전략. 두 지표의 동시 확인으로 신호 품질 향상.

## 전략 개요

- **진입 조건**: TrendType == +2.0 AND Supertrend 상승 AND EMA 크로스업(롱)
- **방향성 필터**: direction_ema_len EMA
- **청산**: ATR 기반 stop-loss
