# ADR-003. Supertrend 단일 전략 채택

## Status

Accepted (2026-05-18) — Phase 5 메인넷 전환 확정

## Context

### 전략 선택 과정

**ADR-002 (2026-05-02)**: Multi-symbol Funding Arbitrage 도입 검토
- 백테스트 Track B: 6종 심볼, 3개 전략 후보
- 합격 기준: CAGR ≥ 20%, Sharpe ≥ 2.5, MDD ≤ -8%

**Track B 결과** (2026-05-17 완료):
- Multi-symbol FA: 합격 기준 미충족 (CAGR +8.3%, Sharpe 1.1)
- Cross-exchange FA: 합격 기준 미충족 (CAGR +11.2%, Sharpe 1.4)
- Dynamic Threshold FA: 합격 기준 미충족 (CAGR +14.5%, Sharpe 1.9)

**결론**: ADR-002의 조건부 정책 전환이 불충족 → BTC-only (ADR-001) 유지 필요

### 대안 탐색: Supertrend 4h Long-only

**백테스트 결과** (Bybit 네이티브 4h, combo #7908, 9년 데이터: 2017-08-17 ~ 2026-04-30, 2026-06-14 재빌드):
- **CAGR**: +137.64% (평균연율)
- **Sharpe ratio**: 1.349
- **MDD (Maximum Drawdown)**: -73.29%
- **거래 횟수**: 360회
- **수익성**: 2024-2026 수익 포함

**성능 해석**:
- CAGR +137.64% > 고위험 (MDD -73.29%) 인정 가능
- Sharpe 1.349: 중등 안정성 (펀딩 차익 3.5 대비 낮음, but 충분함)
- 단일 심볼 (BTC) 운영으로 ADR-001 정책 일치

### 사용자 승인

**2026-05-18 확정 / 2026-05-24 combo 업그레이드**:
- 극단 리스크 MDD -84.28% 수용
- 메인넷 $200 USDT 초기 자본 배치
- Phase 5 즉시 전환

---

## Decision

**Phase 5 메인넷 운영 전략: Supertrend 4h Long-only (combo #7908), 3x 레버리지**

### 구체 사양

1. **전략 ID**: `supertrend-01`
2. **기본 설정**:
   - 기법: Supertrend (Atr factor: 3.0, Multiplier: 10)
   - 시간틀: 4h (4시간봉)
   - 방향: Long-only (숏 금지)
   - 레버리지: 3x (하드 캡, 초과 불가)
   - 심볼: BTCUSDT (단일)

3. **진입 조건**:
   - Supertrend 상향 돌파 + Close > Supertrend 상한
   - 펀딩비 > 0.0001 (또는 설정값)

4. **청산 조건**:
   - Supertrend 하향 돌파 또는 손절매
   - Kill Switch 발동 시 즉시 전량 청산

### 폐기 전략

다음 전략은 **완전 삭제**:
- **Funding Arbitrage (FA)**: 2026-05-18 자정 이후 미운영 (본 ADR-004 참조)
- **Adaptive DCA**: 2026-05-18 이후 미운영 (본 ADR-005 참조)

### 백테스트 인프라 보존

**제네릭 백테스트 시스템** (`backtest/strategies/`, `backtest/scripts/`) 는 향후 전략 R&D 용으로 보존:
- Jesse 엔진 (외부 관리)
- 자체 백테스트 엔진 (개발 중)
- 데이터 수집 & 분석 스크립트

## Consequences

### 긍정적 (Positive)

#### 1. 단순한 운영

- 단일 전략 = 모니터링 대상 최소화
- Kill Switch 설정 명확 (1개 전략 ID)
- Telegram 알림 단순화

#### 2. 검증된 백테스트 성과

- 9년 데이터(Bybit 네이티브 4h)에서 CAGR +137.64% 실증 (2026-06-14 재빌드)
- 수익성 명확 (연율 기준)
- 계절성/주기성 패턴 파악됨

#### 3. BTC-only 정책 일치

- ADR-001 (BTC 단일 운영) 완전 준수
- 다중 심볼 운영의 복잡도 회피
- 유동성 최상(BTC) 심볼만 활용

#### 4. 고위험의 명확한 수용

- MDD -73.29% 명시적 승인 → 회원과의 신뢰도 향상
- 포지션 보호 메커니즘 강화 (Kill Switch 4단계 계층 유지)
- 리스크 공시 이상 (이미 충분히 공개됨)

### 부정적 (Negative)

#### 1. 단일 전략 의존 리스크

- Supertrend 지표만 의존 → 지표 오류/버그 영향 직결
- 시장 환경 변화 시 대체 전략 없음
- 다각화 효과 불가능

#### 2. 고위험 드로다운 (MDD -73.29%)

- 초기 자본 $185.31 → 최악 $49.80 가능
- 심리적 부담 (73%+ 손실)
- 극단 시장 변동(2018년 같은 약세) 시 포지션 보호 중요

#### 3. 4h 시간틀의 신호 지연

- 1h 또는 15m 추종 대비 시장 대응 느림
- 갭(gap) 리스크 (특히 주말 긴급 이벤트)

#### 4. 거래 빈도 낮음

- 360회/9년 ≈ 40회/년 ≈ <1회/주 (펀딩 차익 6회/월 대비 매우 낮음)
- 자본 회전율 하락

### 리스크 및 완화 조치

#### 리스크 1: Supertrend 신호 오류

**증상**: 지표 계산 오류 → 거짓 진입/청산  
**완화**:
- `backtest/strategies/external/SupertrendStrategy.py` 유닛 테스트 추가
- 라이브 신호 vs 백테스트 신호 일일 비교
- 이상 지표 감지 시 Telegram 알림 추가

#### 리스크 2: Kill Switch 실패

**증상**: 극단 시장 변동 시 청산 불가능  
**완화**:
- Kill Switch 4단계 계층 유지 (기존)
- 1시간 내 수동 청산 SOP 확보
- Bybit API 연결 상태 모니터링

#### 리스크 3: 펀딩비 침식

**증상**: 2024-2026처럼 펀딩비 → 0 추세 (백테스트 가정 깨짐)  
**완화**:
- 월별 펀딩비 추이 모니터링
- 펀딩비 < 0.00005 지속 3개월 시 ADR 재검토

## Rejected Alternatives

### ❌ 대안 A: Multi-symbol FA 도입

```
이유:
- ADR-002 합격 기준 미충족
- 운영 복잡도 증가 (Telegram, Kill Switch)
- 데이터 부족 심볼 존재 (PEPE)
```

### ❌ 대안 B: BTC-only FA 유지

```
이유:
- 펀딩비 알파 소멸 추세 (0.0003 → 0.0001)
- 극저 펀딩비 환경에서 수익성 악화
- 2024-2026 성과 불만족
```

### ❌ 대안 C: 포트폴리오 다전략 운영

```
이유:
- 운영 복잡도 과도 (N개 전략 모니터링)
- Kill Switch 재설계 필요
- Phase 5 즉시 전환 요구사항 불만족
```

### ❌ 대안 D: 1h/15m 시간틀 Supertrend

```
이유:
- 백테스트 신뢰도 낮음 (고주파 노이즈)
- 거래 수수료 급증 (매월 1000+ 거래)
- 운영 피로도 ↑
```

### 3. 시작/종료 프로토콜

```bash

# 2. supertrend 서비스 시작 → /status 확인

```

**종료 (도커 재시작/배포)**:

### 4. 모니터링 규칙

**Telegram 알림** (`dispatcher.py`):
- 진입/청산 신호: 모든 거래

- 펀딩 수익: 일일 요약

- 포지션 종료: `POSITION_CLOSED`
- 오류/이상: `SERVICE_HEALTH_FAIL`

## 변경 방지 규칙

1. **Supertrend 지표 파라미터 변경 금지**:
   - atr_factor, multiplier는 백테스트 기준 유지
   - 변경 시 새 ADR 작성 필수

2. **레버리지 상향 금지**:
   - 3x는 하드 캡 (초과 절대 불가)
   - 변경 사유: 포지션 보호 임계값 재계산 필요

3. **심볼 추가 금지**:
   - BTCUSDT만 거래 (ADR-001 유지)
   - Multi-symbol 도입 시 새 ADR 필수

4. **방향 변경 금지**:
   - Long-only 원칙 (숏 금지)
   - 양방향 운영 시 새 ADR 필수

## 향후 재검토 조건

이 정책은 다음 중 하나 발생 시 재검토합니다:

1. **CAGR 급락**: 6개월 CAGR < 20% 지속
2. **Sharpe 악화**: Sharpe < 0.8 지속
3. **Kill Switch 다중 발동**: 월 3회 이상 Level 4 발동
4. **펀딩비 소멸**: 평균 펀딩비 < 0.00001 지속 3개월
5. **Supertrend 신호 신뢰도 저하**: 위신호율 > 30%

재검토 시: **새 ADR 작성** (이 ADR을 Supersede)
